📘 GradTrack Web App

A student tracking system for managing academic and employment data with role-based access.

🚀 Features

🔐 Role-based login (Admin, Advisor, Faculty, Student)

🎓 Manage student records (GPA, major, degree)

💼 Track employment data (salary, job status, internships)

🔍 Search and filter students

📊 Generate reports (GPA, salary, major, etc.)

📝 Students can submit update requests


🧠 Tech Stack

Java

GUI-based application


🛠️ Setup

git clone https://github.com/locbuigia/GradTrackWebApp.git

cd GradTrackWebApp

Open in IntelliJ / Eclipse

Run the main class


🔑 Default Login

Role	Username	Password

Admin	admin	admin

Advisor	advisor	advisor

Faculty	faculty	faculty
